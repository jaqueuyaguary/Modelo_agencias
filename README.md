# Modelo_agencias

Este proyecto realiza un análisis econométrico con datos de panel para identificar los principales determinantes de la rentabilidad de las agencias financieras, medida a través del Retorno sobre Activos (ROA). A partir de información contable mensual, se construyen indicadores financieros, se desarrollan análisis descriptivos y de correlación, y se estiman modelos de efectos fijos y aleatorios con inferencia robusta.

En el codigo se detalla paso a paso el procedimiento realizado en R (versión 4.0 o superior).
